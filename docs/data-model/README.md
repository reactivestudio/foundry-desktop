# Кадры к модели данных

Всё, что нужно, чтобы кадры в [../data-model.md](../data-model.md) были
воспроизводимы, а не подрисованы руками.

## Состав

| Файл | Что это |
|---|---|
| `crops.json` | 16 источников и 141 вырезка: у каждой — прямоугольник кадра и прямоугольник поля, которое надо обвести |
| `make-crops.py` | генератор: режет источники, рисует янтарную рамку и стрелку, кладёт результат в `img/` |
| `build-page.py` | сборщик одностраничного HTML: markdown плюс кадры, вшитые как data URI |
| `img/` | 141 вырезка в WebP, около 1.8 МБ; это то, что видно в документе |

Координаты в `crops.json` — в пикселях источника: `crop` — что вырезаем,
`target` — что обводим внутри вырезанного. Обе четвёрки `[x, y, w, h]`.
Правится только манифест; картинки после правки перегенерируются целиком.

## Источники

Кадры сняты с интерфейса Super Simple Software Factory (IndyDevDan) — это
референс, а не наш продукт. Сами скриншоты в репозиторий не кладутся:
31 МБ чужих экранов здесь не нужны, вырезок для чтения документа достаточно.

Поле `sources` в `crops.json` хранит имена файлов и ширину каждого. Ширина —
не украшение: по ней генератор пересчитывает координаты, если снимок пришёл в
другом масштабе. Чтобы перерезать кадры, нужен каталог с этими файлами.

## Перегенерация

Вырезки — после правки `crops.json`:

```bash
SRC=~/Desktop/model python3 docs/data-model/make-crops.py
```

Одностраничный HTML — после правки `data-model.md` или вырезок:

```bash
python3 docs/data-model/build-page.py
```

Нужен Pillow. Переменная `SRC` по умолчанию `~/Desktop/model`.
